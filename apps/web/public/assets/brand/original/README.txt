zft. logo package

logo/      SVG marks, wordmarks and lockups. "on-dark" = pale ink for dark backgrounds, "on-light" = dark ink for light backgrounds. Transparent.
app-icon/  1024px app icons (SVG + PNG).
avatar/    512px circular avatars (SVG + PNG).
favicon/   PNG favicons 16/32/48, apple-touch-icon 180, SVG favicons. Use the tile version at 16px.

Wordmark font: IBM Plex Mono SemiBold (Google Fonts). Wordmark/lockup SVGs reference the font by name; convert to outlines in a vector editor before use where the font isn't installed.

  Green dark  #108A3F (mono-green on light)
  Ink         #0E0F0E
